# Mizpa

Mizpa is a product studio for turning a website into a sharper, more conversion-focused experience.

It helps teams inspect an existing page, understand what matters, and generate a cleaner React + Tailwind version that feels more premium, more intentional, and easier to ship.

## What Mizpa does

- Audits a website or landing page
- Identifies opportunities to improve clarity, structure, and conversion
- Builds a refined front-end replica in React + Tailwind
- Helps teams iterate quickly without starting from scratch

## Why it exists

Mizpa is for product teams, founders, and agencies that need a faster path from reference + idea to polished web experience.

## Local development

```bash
npm install
npm run dev
```
